## AGENT-1 — STABILITY GUARD

**역할**: 안정성 감시 / SHA 검증 / 회귀 차단

**책임**:
- bootstrap deterministic 검증
- L2 replay 실행
- SHA drift 탐지
- regression 감시
- semantic drift 차단

**전용 작업**:
- bootstrap.js replay
- s2/s3 SHA 비교
- smoke harness 실행
- PASS matrix 기록

**수정 가능 파일**:
```
tests/*
scripts/*
tools/*
docs/verification/*
```

**수정 금지**:
- `eval-special-forms.ts`
- `eval-builtins.ts`

**필수 출력**:
- PASS/FAIL report
- SHA report
- deterministic status

```bash
# AGENT-1 표준 검증 절차
npm test -- --passWithNoTests
node bootstrap.js compile bootstrap.js /tmp/s2.js
node /tmp/s2.js compile bootstrap.js /tmp/s3.js
sha256sum bootstrap.js /tmp/s2.js /tmp/s3.js
node bootstrap.js run tests/smoke.fl
```

## AGENT-2 — SAFE STDLIB

**역할**: 저위험 stdlib 확장

**담당**:
- `file-read-or` — 파일 없으면 기본값 반환
- `http-get-key` — API Key 인증 GET
- `shell-exec-stdout` — stdout 직접 반환
- `env-load` auto — 초기화 시 .env 자동 로드
- alias helpers — str-contains-in, str-replace-in 등
- nil-safe wrappers

**수정 가능 파일**:
```
src/stdlib-http.ts
src/stdlib-file.ts
src/stdlib-process.ts
src/stdlib-data.ts
src/stdlib-cache.ts
src/interpreter.ts
```

**금지**:
- evaluator semantics 변경
- bootstrap 구조 변경

> **원칙**: "helper 우선, semantics 변경 금지"

## AGENT-4 — CORE ISOLATION

**역할**: 위험 코어 수정 전담

**담당**:
- `try/catch` 완전 구현
- error object wrapping
- exception propagation

**수정 가능 파일**:
```
src/eval-special-forms.ts
src/eval-builtins.ts
```

**강제 규칙**:
- isolated commit only
- commit당 semantic change 1개
- bootstrap replay mandatory

**필수 테스트**:
```lisp
; 1. nested try
(try (try (/ 1 0) (catch $e "inner")) (catch $e "outer"))

; 2. rethrow
(try (try (error "x") (catch $e (error $e))) (catch $e (error-message $e)))

; 3. division by zero
(try (/ 1 0) (catch $e (error-message $e)))

; 4. runtime error wrap
(try (get nil "key") (catch $e "safe"))

; 5. stack consistency
(try (error "test") (catch $e (error-type $e)))
```

**금지**:
- unrelated refactor
- formatting-only churn
- stdlib 혼합 수정

> **원칙**: "semantic mutation 최소화"
