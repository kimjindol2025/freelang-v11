# D-6 process-limit 기본 격리 실행

기준 가지 `db-stability`, 시작 HEAD `93563dd8dd5866c97880ce49c5cddbc1f6890c6b`. 실행 위치: 메인. 무거운 시험은 공용 잠금 아래에서 실행했다. seed·판정식·기대값은 변경하지 않았다.

## 1. 기본 방식과 메인 선택 옵션

[run-task931.sh](https://github.com/kimjindol2025/freelang-v11/blob/db-stability/tests/run-task931.sh):36에서 기본값을 `isolated`로 정하고, :47의 `main` 선택을 `FL_FORK_LIMIT_MODE=main`으로 남겼다. :62–88은 하위 UID에서 fork 시험을 실행한다. [db-fork-probe.c](https://github.com/kimjindol2025/freelang-v11/blob/db-stability/tests/db-fork-probe.c):50, :76은 하위 UID 안에서 사용자 과정·태스크 수를 직접 측정해 태스크 수 + 5 제한을 설정한다. [run-db-fork-cause.sh](https://github.com/kimjindol2025/freelang-v11/blob/db-stability/tests/run-db-fork-cause.sh):16은 D-5의 기존 메인 비교를 명시적으로 선택한다.

기존 `FAILED_SLOTS>0`, `SUCCESSFUL_SLOTS>0`, 합계 20, `PARALLEL_DONE`과 최종 `FORKFAIL_SUMMARY=9/9` 판정은 그대로다. 메인 선택 옵션 확인 원문:

```text
D6_MAIN_OPTION_RC=0 MODE=PARALLEL_MODE=main
```

## 2. 격리 불가 시 비통과

격리 명령이 실패하도록 시험용 명령을 앞에 놓고 실제 `run-task931.sh`를 실행했다. 성공으로 건너뛰지 않고 RC 2와 이유를 남겼다. [run-db-isolated-default.sh](https://github.com/kimjindol2025/freelang-v11/blob/db-stability/tests/run-db-isolated-default.sh):9, :25는 이 검증과 기본 방식 50회 집계다. 집계 스크립트는 실행 전에 커밋했고 실행 중 수정하지 않았다.

```text
D6_SKIP_RC=2 SKIP_REASON=isolated-uid-or-limit-setup-failed
```
