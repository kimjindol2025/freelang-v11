## 1. 자가호스팅 (L2) 실제 상태

### 테스트 방법

```bash
node bootstrap.js compile self/all.fl -o /tmp/s1.js  # ✅ 성공
node /tmp/s1.js                                       # ❌ 즉시 크래시
```

### 오류

```
/tmp/s1.js:280
const _fl_is_digit_q = (c) => ...
      ^
SyntaxError: Identifier '_fl_is_digit_q' has already been declared
```

### 근본 원인

codegen이 prelude 함수를 **중복 선언**함.  
`const _fl_is_digit_q`가 같은 파일에 두 번 생성됨.  
이는 TCP 빌트인 추가(S41.5) 이후 도입된 **회귀 버그**로 추정.

### 단계별 상태

| 단계 | 설명 | 상태 |
|------|------|------|
| L0 | TypeScript → bootstrap.js | ✅ |
| L1 | bootstrap.js → self/all.fl 컴파일 | ✅ |
| L2 | stage1.js 실행 가능 | ✅ — TDZ 버그 수정 (2026-05-17) |
| L3 | stage1.js로 self/all.fl 재컴파일 | ❌ 미달성 |

**실제 달성률: L1/L2 완료 / L3 진행 중**
