## 특별 규칙

### Rule 1: `(= arr [])` deep equal 금지

```lisp
;; ❌ 금지: eval-builtins의 = 연산자 deep equal 변경
(= [] [])  ; 현재 false → true로 바꾸지 않음

;; ✅ 대신: empty? helper 추가
(empty? [])      ; → true
(empty? "")      ; → true  
(empty? nil)     ; → true
(array-empty? [])  ; → true (배열 전용)
```

### Rule 2: `set!` closure mutation 금지

```lisp
;; ❌ 금지: closure chain 통한 상위 스코프 변수 수정
(define $x 1)
(defn inc-x [] (set! $x (+ $x 1)))  ;; 작동 보장 안 함

;; ✅ 권장: atom 패턴
(define $x (atom 1))
(defn inc-x [] (swap! $x (fn [$v] (+ $v 1))))
```

### Rule 3: try/catch 구현 규칙 (Phase C)

- JS Error 직접 노출 금지 → FreeLang runtime error object wrapping
- error object 구조: `{"type" "RuntimeError" "message" "..." "stack" "..."}`
- nested try regression test 필수 추가
- 매 commit 전후 bootstrap SHA 비교 기록
- Phase A/B 완전 완료 후에만 진행

### Rule 4: bootstrap.js 재생성

- Phase A 전체 완료 후 **1회만** 재생성
- try/catch 완료 후 **1회만** 재생성
- 중간 재생성 금지

- `src/stdlib-mariadb.ts` — `mariadb_one` nil 안전화, `db_exec` 단일값 자동 배열
