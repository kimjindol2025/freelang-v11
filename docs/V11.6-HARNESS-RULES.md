# FreeLang v11.6.x Stability Harness Rules

**적용 버전**: v11.6.20+  
**목표**: self-host bootstrap 안정성 · semantic drift 차단 · evaluator 오염 방지 · PASS 기반 개발 강제 · SHA 기반 결정성 유지

---

## [HARNESS-CORE-001] 코어 안정성 우선 원칙

1. evaluator 의미 변경 금지 우선
2. stdlib/helper 방식 우선
3. 기존 bootstrap SHA 변화 최소화
4. self-host determinism 유지
5. regression 발생 시 즉시 rollback

**금지**:
- 이유 없는 evaluator 수정
- 동작 의미 변경 후 테스트 추가만으로 정당화
- bootstrap mismatch 상태 push

---

## [HARNESS-PHASE-001] 작업 단계 규칙

### SAFE PHASE (우선 진행)
- stdlib helper
- alias
- nil-safe wrapper
- docs
- convenience API

### DANGEROUS PHASE (후순위, isolated)
- `eval-special-forms.ts`
- `eval-builtins.ts`
- closure semantics
- equality semantics
- exception propagation
- scope chain mutation

**규칙**:
- SAFE PHASE 먼저 완료
- DANGEROUS PHASE는 isolated commit 강제
- dangerous 작업은 **1 commit = 1 semantic change**

## [HARNESS-BOOTSTRAP-001] Bootstrap 고정점 규칙

모든 dangerous phase 종료 후 필수 실행:

```bash
node bootstrap.js compile bootstrap.js /tmp/s2.js
node /tmp/s2.js compile bootstrap.js /tmp/s3.js

sha256sum bootstrap.js
sha256sum /tmp/s2.js
sha256sum /tmp/s3.js
```

**성공 조건**:
- SHA 3개 동일
- 출력 동일
- compile 결과 deterministic

**실패 조건**:
- SHA mismatch
- whitespace drift 반복 발생
- compile output mutation

**실패 시**:
- 즉시 원인 분석
- 마지막 semantic commit rollback 검토

## [HARNESS-EXCEPTION-001] 예외 처리 규칙

try/catch 구현 시:

1. JS Error 직접 노출 금지
2. FreeLang error object wrapping 강제  
   → `{"type" "RuntimeError" "message" "..." "stack" "..."}`
3. nested try regression 필수
4. rethrow behavior 명시
5. stack shape deterministic 유지

**필수 테스트 케이스**:
```lisp
; 1. divide by zero
(try (/ 1 0) (catch $e (error-message $e)))

; 2. nested catch
(try
  (try (throw "inner") (catch $e "caught-inner"))
  (catch $e "caught-outer"))

; 3. throw inside catch
(try
  (error "outer")
  (catch $e (try (error "inner") (catch $e2 (error-message $e2)))))

; 4. runtime builtin error
(try (get nil "key") (catch $e "safe"))

; 5. stdlib async boundary
(try (http-get "invalid-url") (catch $e (error-type $e)))
```

## [HARNESS-RECORD-001] 기록 규칙

모든 major phase 기록 항목:

| 항목 | 내용 |
|------|------|
| commit hash | 7자리 |

## [HARNESS-STABILITY-001] 최종 안정성 원칙

FreeLang v11은:
- 실험용 런타임이 아니라
- **self-host 안정화 단계 언어**이다.

따라서:
- 기능 수 증가보다
- **의미 안정성 유지가 우선**이다.

**최우선 목표**:
- deterministic bootstrap
- semantic consistency
- regression-free evolution
- stable self-host pipeline
