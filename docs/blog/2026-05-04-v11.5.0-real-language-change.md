**언어 코어 변경: 0.**

"Phase X 시작" 이라고 거창하게 썼는데, 실제로는 *우리 도구가 발전*했을 뿐

**stdlib에 `str-to-num`이 등록 안 되어 있어서** 변환된 코드는 실행 안 됨.

부정직한 도구를 자랑한 셈.

## 구현: stdlib-kebab-aliases.ts

110줄. 핵심:

```ts
const SKIP_NAMES = new Set([
  "define", "fn", "defn", "if", "cond", "let", ...,  // syntax form 제외
  "+", "-", "*", "/", ...,                            // 연산자 제외
]);

const PREDICATE_NAMES = new Set([
  "file_exists", "file_is_dir", "fl_require",  // 술어성 — ? suffix도 추가
]);

function snakeToKebab(name: string): string {
  return name.replace(/_/g, "-");
}

export function createKebabAliasesModule(modules) {
  const aliases = {};
  const allNames = new Set();

  // 기존 이름 수집 (충돌 방지)
  for (const mod of modules)
    for (const name of Object.keys(mod)) allNames.add(name);

  // snake → kebab alias 등록
  for (const mod of modules) {
    for (const [name, fn] of Object.entries(mod)) {
      if (typeof fn !== "function") continue;
      if (SKIP_NAMES.has(name) || !name.includes("_")) continue;

      const kebab = snakeToKebab(name);
      if (!allNames.has(kebab)) {
        aliases[kebab] = fn;
        allNames.add(kebab);
      }

      // 술어성 함수: ? suffix도 추가
      if (PREDICATE_NAMES.has(name)) {
        const predicate = kebab + "?";
        if (!allNames.has(predicate)) {
          aliases[predicate] = fn;
          allNames.add(predicate);
        }
      }
    }
  }

  return aliases;
}
```

`stdlib-loader.ts`에서 모든 모듈 등록 후 마지막에 호출:
```ts
interp.registerModule(createKebabAliasesModule([
  fileModule, httpModule, dataModule, ...,  // 25개 모듈
]));
```

`FL_DEBUG_KEBAB=1` 환경변수로 등록 통계 확인:
```
[kebab-aliases] +400 (예: file-read, file-write, file-exists, file-delete, file-append ...)
```

## 5가지 통일 규칙 — 정직한 진행률

오전에 *"5가지 통일 규칙"* 을 자랑했다. v11.5.0 시점 진짜 진행률:

| 규칙 | 상태 | 비고 |
|------|------|------|
| 1. 인자 순서 통일 | ❌ 제안만 | 위험도 높아 마지막 |
| 2. **kebab-case** | ✅ **구현** | v11.5.0 (400개 alias) |
| 3. 술어 `?` suffix | △ 부분 | file-exists? 등 일부만 |
| 4. HTTP 응답 분리 | ❌ 제안만 | 별도 함수 추가 필요 |
| 5. `$` 접두사 선택 | ❌ 제안만 | 파서 변경 |

**5/5 → 1.5/5.** 80% 안 했다고 인정.

그래도 v11.4.3보다는 *진짜* 다. **하나는 끝까지 했다.**

## migrate 도구 정정

v11.4.3에선 변환된 코드가 작동 안 했다. v11.5.0에선 작동.

```bash
$ freelang-migrate --help
사용법: freelang-migrate <path> [옵션]

옵션:
  --apply              실제 적용 (기본: dry-run)
  --no-arg-order       인자 순서 변환 제외
  --remove-dollar      $ 접두사 제거

전제 (중요):
  변환된 kebab-case 코드는 v11.5.0+ 런타임에서 작동합니다.
  v11.4.x 런타임에서는 변환된 코드가 "Function not found" 에러.
  → 런타임 버전 확인: node bootstrap.js --version
```

명시적 경고 추가. *전제* 명문화.
