## 🚀 5가지 강화 기능 추가

v11.7.4-enhanced로 다음 5가지 기능을 추가했습니다.

### 1. 🔥 Hot Reload — 파일 변경 감지 자동 재로드

```lisp
(load "stdlib/devtools-reload.fl")
(watch-and-reload "src")  ;; 파일 자동 감시 + 재로드
```

**효과**: 개발 사이클 30초 → 3초

### 2. 🐛 Enhanced Stack Trace — 향상된 에러 추적

```lisp
(load "stdlib/enhanced-errors.fl")
(with-trace "handler" my-handler)
(catch e (print-error-detailed e))  ;; 변수값 + 콘텍스트 출력
```

**효과**: 디버깅 시간 50% 단축

### 3. 📦 Module System — 의존성 관리

```lisp
(load "stdlib/modules.fl")
(module-import "routes/api" {:as "api"})
(check-circular-dependencies)  ;; 순환 참조 자동 감지
```

**효과**: 프로젝트 규모 확장성 향상

### 4. 🔍 Runtime Type Checking — 함수 인자 검증

```lisp
(load "stdlib/type-check.fl")
(defn-typed add [a:int b:int] -> int (+ a b))
;; 타입 검증 + 에러 메시지
```

**효과**: AI 코드 생성 정확도 ↑ , 버그 ↓

### 5. 💻 VS Code Extension — IDE 통합

기본 IDE 지원:
- Run File
- Hot Reload
- Format + Lint
- Server Management
- Hover Info + Completion

## 🎁 지금 시작하기

### 설치
```bash
npm install freelang-editor
```

### 첫 번째 앱
```bash
cat > app.fl << 'EOF'
(server-start 3000)
(define routes {
  :get {"/" (fn [req] 
    (server-json {:status "ok" :message "Hello FreeLang!"}))}
})
EOF

node bootstrap.js serve app/
```

### 강화 기능 활성화
```bash
cat > enhanced.fl << 'EOF'
(load "stdlib/devtools-reload.fl")
(load "stdlib/enhanced-errors.fl")
(load "stdlib/type-check.fl")

(watch-and-reload "src")
(println "✅ Hot Reload active!")
EOF

node bootstrap.js run enhanced.fl
```
